Delivo - Food Delivery PWA Mobile Html Template

Delivo is a premium, high-quality Progressive Web App (PWA) mobile template designed specifically for food delivery services, restaurants, and culinary businesses. Built with Bootstrap 5 and modern web technologies, Delivo offers a native app-like experience directly in the browser.

With a stunning dark/orange color scheme and pixel-perfect design, Delivo ensures your users have a seamless and engaging experience whether they are ordering food, tracking deliveries, or managing their profile.

Key Features

PWA Ready
Installable on mobile devices (iOS & Android) with service worker support for offline capabilities.
Bootstrap 5 Framework
Built on the latest Bootstrap 5 for robust responsiveness and easy customization.
30+ HTML Pages
Comprehensive screens including Onboarding, Authentication, Home, Menu, Cart, Checkout, Order Tracking, Profile, and more.
W3C Validated Code
Clean, semantic, and error-free HTML code verified for standards compliance.
SASS Included
Well-organized SCSS files for easy styling updates and variable management.
Fully Responsive
Optimized for all mobile screen sizes, ensuring a perfect look on every device.

Pages Included

  • Onboarding & Splash: Splash Screen, Onboarding Slides (1-3)
  • Authentication: Sign In, Sign Up, Verification (OTP), Forgot Password, Create Password
  • Main App: Home Dashboard, Search, Filter, Notifications
  • Food & Menu: Menu Details, Favorites, Hot Deals
  • Ordering Process: Cart, Checkout, Payment Selection, Add Card, Order Success
  • Tracking: Order Tracking (Map & Status), Driver Rating, Order History
  • User Profile: Profile Settings, Edit Profile, Payment Methods, Addresses
  • Utility Pages: 404 Error, Help Center, Privacy Policy, Terms & Conditions

Files Structure

  • index.html - Main entry file
  • assets/css/ - Computed CSS styles
  • assets/scss/ - Source SASS files
  • assets/img/ - Images and icons
  • assets/js/ - JavaScript files

Technologies Used

  • HTML5 & CSS3
  • Bootstrap 5.3.x
  • SASS (SCSS)
  • Vanilla JavaScript
  • Google Fonts (Plus Jakarta Sans)
